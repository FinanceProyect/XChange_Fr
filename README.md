# CambioJoyasLourdes — Frontend

Frontend de la aplicación de gestión de compra y venta de divisas de Cambio Joyas Lourdes.

## Tecnologías

- React 19 + TypeScript
- Vite
- React Router DOM
- Tailwind CSS v4

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
```
